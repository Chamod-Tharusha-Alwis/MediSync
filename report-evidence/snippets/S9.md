**What it does:** A dispense runs in a MongoDB transaction with a receipt id derived from the prescription, so a retry with the same idempotency key returns the stored receipt and any other second attempt fails with ALREADY_DISPENSED. The prescription is claimed with a conditional update (only while still pending), which is what guarantees one receipt per item when two pharmacies click at the same moment.
