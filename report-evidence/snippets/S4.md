**What it does:** Every triggered detector result becomes an OutbreakAlert document whose id is a hash of the policy, mode, district, disease and source consultations, so a repeated scan updates the same alert instead of creating duplicates. New alerts are always stored as Pending with the severity from the z-score bands, and wait for an administrator to approve them.
