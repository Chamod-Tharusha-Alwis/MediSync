**What it does:** The 14-day trend projection fits an ordinary least-squares line to the daily counts and widens each future point by a Student-t prediction interval (se x sqrt(1 + 1/n + (x - mean)^2 / Sxx)). It runs in the browser for the public and admin trend charts; statsmodels is used only in the offline study, not in this production code.
