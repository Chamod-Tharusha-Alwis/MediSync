## Findings Matrix

| ID | Area | Severity | Observation | Code/Root Cause | Proposed Fix |
|:---:|---|:---:|---|---|---|
| **F1** | Email / Privacy | **Critical** | Consultation Summary email body exposes diagnosis, clinical notes, follow-up, and drug list in plain text and Gmail preview. PDF attachment is unencrypted and auto-previews in Gmail. | `server/src/services/consultationSummaryEmailService.js:215-375` embeds diagnosis, notes, and rx tables directly into email template and attaches unencrypted PDF (`:490`). | Strip all clinical details from subject, preheader, and body. Replace with generic notification ("MediSync: your consultation summary is ready") and secure link to `/verify/:token` (OTP-gated) or patient portal. Remove PDF attachment from email. |
| **F2** | PDF Export / Layout | **High** | PDF header hides "Consult Ref" under QR code; diagonal watermark overlaps body text; "SLMC Registration: SLMC-REG-VERIFIED" is a placeholder; no doctor ID; Patient NIC and Age print "N/A"; PDF date/time shows UTC instead of Asia/Colombo. | `server/src/utils/pdfGenerator.js:46-56` has hardcoded "SLMC-REG-VERIFIED", uses UTC time formatting, lacks doctor ID, prints "N/A" for missing demographics, and has QR/header coordinate collision. | Fix layout grid with dedicated QR box, lighten/relocate watermark, render doctor's real `slmcNumber` (or "not on file") and doctor ID, mask NIC (e.g. `199***123V`), omit "N/A" lines, calculate age from DOB, format timestamps in Asia/Colombo ("Sri Lanka time"). |
| **F3** | Pharmacy UI / Privacy | **High** | Pharmacy "Dispensation History" table, receipts, OTC order summary, and console headers display raw patient NIC instead of patient name. | `client/src/pages/pharmacy/Dashboard.jsx`, `ReceiptModal.jsx`, and backend pharmacy endpoints expose/render patient NIC in plain table columns. | Decrypt and return `patientName` server-side; display patient full name in tables, receipts, OTC summaries; keep NIC input-only during patient search; sweep client for raw NIC leaks. |
| **F4** | UI / Disclaimer Text | **Medium** | Raw debug string `clinicalValidation: not_established` rendered on doctor ML card, medicine safety panel, and public verify page top bar. | Unstyled badge rendered literally across `NewConsultation.jsx`, `MedicineSafetyPanel.jsx`, and `VerifyConsultation.jsx`. | ML card: replace with human advisory "Reference matches only. A clinician must assess; matches are not diagnoses and scores are not probabilities." Medicine safety: "Advisory reference. Clinical assessment required." Verify page: remove completely (not an ML feature). |
| **F5** | Lab Upload & Status | **High** | Lab report upload for `LT-20261109-4514` fails with toast "Upload failed. Check file content." and HTTP 409, while email says report is ready; hospital lab view and patient timeline remain "Pending". | `server/src/controllers/labController.js` upload endpoint rejects repeat upload with 409 without checking file hash idempotency; state machine transitions out of sync between lab order, notification, and patient timeline. | Make upload idempotent (same SHA-256 returns 200); clear error mapping for distinct file types / existing reports; propagate derived `labStatus` consistently across doctor view, hospital view, and patient timeline. |
| **F6** | Pharmacy OTC Checkout | **High** | OTC checkout throws "Dispensing could not be completed atomically. Retry the same checkout."; dropdown says "Select Stock Drug..." implying inventory. | Atlas M0 replica set transient transaction aborts / commit conflicts during single-item OTC checkout; UI label uses "Stock Drug". | Implement bounded retry with backoff for `TransientTransactionError` / `UnknownTransactionCommitResult`; rename UI label to "Select drug" (zero inventory phrasing). |
| **F7** | Safety Engine / Prescriber Override | **High** | Doctor safety panel reports "No known reference interactions detected", but saving triggers blocking red toast "Medication Safety Conflict: Prescribed drugs conflict with patient active medications or safety rules". Client panel checks current prescription pairwise only; server checks active medications. | Inconsistency between client check (`MedicineSafetyPanel.jsx`) and server check (`currentMedicationSafety.js` / `consultationCommandService.js`). Hard blocks prevent doctor completion. | Unify client and server checks into single engine evaluating current + active medications; convert hard-block to advisory with doctor acknowledgment (reason required for severe/critical); never block doctor. |
| **F8** | Public Endpoints / Health Stats | **High** | `GET /api/alerts/active` returns 401 Unauthorized (documented as Public); `GET /api/public/health-stats` returns 503 `PUBLIC_HEALTH_UNAVAILABLE` on unreviewed real data. | Route middleware order requires auth on alerts; `server/src/services/publicHealthStats.js:108` throws `REPORTING_REVIEW_REQUIRED` (503) if any unverified consultation exists. | Make `/api/alerts/active` public (no auth, rate-limited); update public health endpoint to return 200 with `verifiedCases` and `awaitingReviewCount` instead of 503; provide admin surveillance review interface. |
| **F9** | ML Service Logging | **Medium** | Render ML microservice dashboard has zero request logs despite handling live doctor inference. | `ml-engine/app.py` lacks structured request/response stdout logging; gunicorn runs without `--access-logfile -`. | Add structured per-request stdout logging (`request_id`, path, status, latency ms, symptom count, tier, top confidence, no PII); add backend `[ML]` call logger. |
| **F10** | Email Noise & Rate Limit | **Medium** | 26 emails in 1 hour; every login sends "Login from NEW Unrecognized Device" for same browser; multiple "Medication Has Been Dispensed" emails in seconds. | Missing trusted device token persistence after login; dispensing triggers per-line-item notifications. | Persist trusted device marker (hashed, httpOnly cookie/device record, 24h throttle); consolidate dispensing emails to one per consultation order; add daily email cap counter in server. |
| **F11** | Audit Log & User Search | **Medium** | Mutating routes lack uniform audit trail; admin cannot search audit logs or users by email. | Incomplete audit calls across endpoints; audit logs intentionally omit plain email for privacy but lack query-time email-to-id resolution. | Create route audit coverage matrix; implement query-time email-to-id resolution for admin search; add name/email/role search with pagination to Users dashboard. |
| **F12** | Formulary Data Quality | **Medium** | Formulary typo "Penicitin Capsule 10'S"; typed "Citalopr" gives "Unresolved ingredient(s)"; ICD-11 code `6A70` labeled "ICD-10"; multiple overlapping active prescriptions. | Typo in drug catalog; prefix matching fails to resolve root generic; `whoIcd11Service` codes misattributed to ICD-10 default; lack of auto-supersession. | Correct "Penicitin" -> "Penicillin"; enhance autocomplete prefix matching (`citalopr` -> `citalopram`); display true ICD-11 badge; implement active prescription auto-supersession. |
