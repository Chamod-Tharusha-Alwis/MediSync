This document provides an exhaustive, annotated architectural directory map of the MediSync healthcare platform. Every source code, configuration, database, asset, script, and documentation file across the entire repository is listed below with an explanation of its role in the system.

## 4. Machine Learning & Outbreak Surveillance Engine (`/ml-engine`)

### 4.1 ML Engine Root (`/ml-engine`)
* `.dockerignore` — Defines local training cache and virtual environment files excluded when building the ML Engine Docker image.
* `.env` — Local environment variables file configuring Flask server ports, allowed CORS origins, and internal server-to-server authentication tokens.
* `.env.example` — Template environment file documenting required configuration variables for deploying the ML Engine.
* `Dockerfile` — Docker containerization script setting up a Python 3.10 runtime, installing scientific libraries (Scikit-Learn, Pandas, Prophet), and exposing the Flask API.
* `app.py` — Master Flask API application running the AI diagnostic symptom checker, drug-drug interaction verifier, and Weighted Outbreak Anomaly System.
* `dump.json` — Diagnostic dump file capturing raw serialized ML model prediction outputs and feature vector states for debugging.
* `medisync.db` — High-performance SQLite relational database storing historical district disease counts, anomaly feedback logs, and the 71,700+ ICD-10 disease directory.
* `preprocess_datasets.py` — Data transformation script that cleans raw medical CSV datasets, normalizes symptom text, and builds TF-IDF vector matrices.
* `requirements.txt` — Python package dependency file listing required scientific libraries including Scikit-Learn, Pandas, NumPy, Prophet, and Flask.
* `seed_local_icd10.py` — Ingestion script that parses the global 71,700+ ICD-10 code dataset, assigns danger levels (`High`, `Medium`, `Low`), and populates SQLite.
* `test_idx.py` — Verification script testing database index performance and query execution speeds across SQLite epidemiological tables.
* `test_outbreak.py` — Automated test script validating Z-score calculation formulas and rolling baseline averages against historical dengue datasets.
* `test_outbreak_logic.py` — Mathematical proof test suite verifying that the Weighted Risk & Anomaly System correctly caps Low Danger diseases and alerts on High Danger epidemics.

### 4.2 Medical Datasets (`/ml-engine/data`)
* `ICD10codes.csv` — Raw comma-separated WHO ICD-10 diagnostic directory containing alphanumeric codes and clinical disease descriptions.
* `Symptom-severity.csv` — Numerical weighting dataset assigning clinical severity scores (1 to 7) to individual patient symptoms used in triage algorithms.
* `dataset.csv` — Primary supervised machine learning training dataset mapping combinations of patient symptoms to confirmed clinical disease diagnoses.
* `db_drug_interactions.csv` — Pharmaceutical database containing documented adverse drug-drug interactions, contraindication severities, and clinical warning notes.

* `drugs_clean.json` — Cleaned, normalized pharmaceutical catalog containing verified drug names, chemical categories, and standard dosages.
* `icd10_clean.json` — Normalized WHO ICD-10 JSON dataset containing 71,704 diagnostic codes used for database seeding and danger level categorization.
* `interactions_clean.json` — Optimized JSON lookup map of drug-drug interactions loaded into Flask memory for sub-millisecond prescription safety checks.
* `medicines.csv` — Auxiliary pharmaceutical inventory dataset listing common Sri Lankan brand names, generic equivalents, and dosage forms.
* `srilanka_dengue_weekly.csv` — Authentic historical epidemiological dataset recording weekly dengue fever case counts across Sri Lankan districts used for time-series calibration.
* `symptom_Description.csv` — Clinical reference text dataset providing patient-friendly medical explanations and background overviews for identified diseases.

* `symptom_precaution.csv` — Clinical recommendations dataset mapping confirmed disease diagnoses to actionable medical advice and home care precautions.

### 4.3 ML Engine Scripts (`/ml-engine/scripts`)
* `fix_endpoint.py` — Maintenance script used to standardize JSON response payload structures across Flask diagnostic and outbreak prediction endpoints.
* `seed_outbreak_data.py` — Epidemiological database seeder that populates SQLite with realistic multi-year historical disease case counts across all 25 Sri Lankan districts.
