# MediSync - Client (Frontend)

The frontend for MediSync, built with React, Tailwind CSS, and Framer Motion. It provides secure dashboards for Patients, Doctors, Pharmacy Staff, and Hospital Admins.

[LIVE URL PLACEHOLDER]

## Environment Variables
Create a `.env.local` file with the following variable names (do NOT include actual secrets):
- `REACT_APP_API_URL`
- `REACT_APP_GA_MEASUREMENT_ID`
- `REACT_APP_SERVER_URL`

## Local Run Instructions
1. Navigate to the `client` directory.
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
